# 可直接套用的骨架：两种玩法形状

> 这里放两个**最小可跑**的参考形状——**全服共同进度条**（一起打 Boss / 一起砍树）与**共享网格画布**（一起涂鸦 / 棋盘 / 地图标记）。不是完整工程，而是"表怎么建、接口怎么切、客户端怎么接、零美术素材怎么做出冲击力"的成品骨架，换表名与字段即可套到同类玩法。

## 一、两种玩法 = 两种表形状

### A. 全服共同进度条

| 用途 | 形状 | 关键点 |
|---|---|---|
| 共享状态（单行） | `id` 主键 + `DEFAULT 1` + `CHECK (id = 1)` | 强制单行；带 `version` 让客户端判断"变了没"；带 `round` 支持"每局/每赛季重置"而不用删数据 |
| 审计流水（只追加） | 一行一次操作，记录谁、多少、何时 | 开 RLS 但**一条策略都不建** → 公网读不到、服务端可查；出问题靠它复盘 |
| 累计榜 | 主键 `(round, owner_id)` | 同一个人多条记录靠 `ON CONFLICT DO UPDATE` 合并成一行，**天然幂等**；索引 `(round, score DESC)` 直接吃 `order by ... limit N` |

### B. 共享网格画布（一行一格）

复合主键 = 格子坐标，值列 = 格子内容，另外两列几乎每个玩法都要：

```sql
nickname   TEXT        NOT NULL DEFAULT 'anonymous',  -- 冗余一份展示名，省一次 join
owner_id   TEXT        NOT NULL DEFAULT auth.uid(),    -- TEXT！auth.uid() 返回的不是 uuid
updated_at TIMESTAMPTZ NOT NULL DEFAULT now()         -- 服务端时钟，同时当增量拉取游标
```

写用 **upsert 覆盖**：同一格被反复改只留最后状态，不需要流水。

## 二、权限与归属（两种形状通用）

- 三件套缺一不可：`GRANT` + `ALTER TABLE ... ENABLE ROW LEVEL SECURITY` + `CREATE POLICY`；**公开只读的表要单独给 `anon` 放行 SELECT**。
- 服务端以 `service_role` 写库时**必须显式带 `owner_id`**——该身份下 `auth.uid()` 取不到用户，靠默认值会落成 NULL。
- 客户端只读公开数据，**写一律经服务端**。

## 三、接口切法：读走 PG REST，写走一个函数，原子性下沉到 RPC

- **读**：客户端带公开凭据直连 PG REST——少一跳、不烧函数调用、天然适配轮询（游标就是 `updated_at`）。
- **写**：**只留一个函数入口**收口，函数负责校验、限频、归属与服务端时间戳。
- **原子性交给 PG 数据库函数（RPC）**：`SELECT ... FOR UPDATE` 和"判定"放在同一个锁里；不要在云函数里做"读—改—写"。RPC 端点在 OpenAPI 文档里可能查不到，落代码前先用一次实测确认路径可用。
- 函数里**零三方依赖**（Node 内置 `http` + 全局 `fetch`）：打包快、没有供应链面。
- 单入口分发用 `?action=<verb>`，**action 优先读 query、再回退路径段**（开了路径透传后路径末段恒为路由名）。
- **限频做两层**：进程内滑动窗口兜并发（判断与写入要在一个原子步里，别"先查后插"），查库计数兜多实例。
- 公开入口用**网关路由**（把鉴权关掉的那条），不要把它写成平台的 `?webfn=true` 调用路径——那条是给服务端带管理凭据用的。
- **函数不要自己写 CORS 头**：经网关时它已按安全域名回填 Origin，再写一个会拼成非法值，浏览器会拦掉所有请求。

## 四、客户端怎么接

**引擎侧（Godot / Unity / Cocos 原生包）**

- 读：`GET` PG REST，轮询（秒级）；写：`POST` 服务端接口；
- 客户端只放公开凭据，**管理密钥一律留在服务端**；
- 高频轮询下每次新建的节点/对象必须释放（Godot `queue_free()`、Unity `using` / `Dispose()`），否则内存持续上涨；
- 加一个 `?bot=N` 开关让客户端每秒自动操作 N 次——无人值守的截图与压测都靠它。

**Web / H5**

- 增量拉取：记住上次拿到的 `updated_at`，只拉新的，别每次拉全量；
- 渲染节奏：新数据入队后**每帧只放 3 格**（`Math.ceil(remaining / 60)` 钳到 3），一批上百格约一秒爬完——看起来"实时"，又不突兀。

## 五、零美术素材也要抓人（视觉模式）

**共享进度条（暗色霓虹）**

| 元素 | 做法 |
|---|---|
| 主角剪影 | 全部程序化多边形：八面棱核（半径大小交替）+ 尖角三角 + 反向旋转的内层多边形 + 斜四边形眼 |
| 外发光 | 兼容渲染器没有 bloom 时，用多层递减 alpha 的同心圆 + 地面弧线伪造 |
| 受击反馈 | 屏幕抖动（衰减式）+ 本体颜色向白 lerp + 横向挤压 + 随机裂痕 |
| 伤害数字 | 上抛 + 重力，前 0.1 秒字号弹入；**深色描边多向偏移**，保证压在任何背景上都读得清 |
| 粒子 | 手写数组就够：命中 10~20 颗、暴击 20 颗、击杀 200+；底部余烬持续升起 |
| 血条 | 加**掉血残影**（残影以固定速度追上来）；低于 25% 换金色；打刻度 |
| 榜单 | 每行背后一条宽度 = 自己 / 榜首 的条；行位次用固定速度 lerp → 反超时能看到名字滑上去 |
| 击杀瞬间 | 全屏闪光 + **只铺一侧的横幅带**（别横跨整屏压住榜单）+ 重生倒计时 |

**共享网格画布**

- 深底 + 10 色等距全饱和霓虹 + 格子外发光 + 扫描线 + 暗角；
- **落子反馈 = 光晕扩散环**：新格子上画一圈 0.5 秒内从 1× 扩到约 4× 的描边，比直接填色"有生命感"；
- 色板点击处追加一个扩散淡出的圆环；全部纯 CSS + `requestAnimationFrame`，不引动画库。

## 六、照做时会遇到的平台行为

- 公开只读表：带公开凭据读返回 200；**客户端直接 INSERT 会被表级权限拒**（`SQLSTATE 42501`）——这就是"写必须走服务端"的直接体现。
- **RLS 开了但没策略**：SELECT **静默返回 `[]` + 200**，不像报错。查空表先怀疑策略，别当成"本来就没数据"。
- 网关路由（鉴权关闭）的写入口：客户端**不带凭据也能通**；参数非法由函数返回 400。
- 并发扣减下沉到 RPC 加行锁后：N 个并发各扣同一个数，返回值严格相差该数，不丢更新。
- 限频按玩家计算：同样节奏换一个 ownerId 就不会被限——所以限频挡的是"同一个人的刷"，不是身份。
- 服务端以 `service_role` 调 PG 时 `auth.uid()` 为空，归属只能由服务端显式写入。

## 七、这两个形状还能套到什么玩法

- **全服共同进度条**：全服 Boss、一起砍树 / 修塔 / 攒经验、限时冲榜活动、公益类"众人拾柴"页面。
- **共享网格画布**：协作画布、棋盘落子、地图标记、房间座位表、格子认领。
