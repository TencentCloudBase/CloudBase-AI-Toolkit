# 信息收集表单场景 Playbook

表单场景模板目录与配套策略。需求澄清时从这里挑最接近的场景起步，字段在模板上改。包内只放官方 skill 覆盖不了的内容：场景字段模型、防重复策略选型、交付话术、汇总页要点。

## 一、场景模板

| 场景 | 典型字段 | 防重复 / 登录 | 交付形态 |
| --- | --- | --- | --- |
| 活动报名表 | 姓名, 联系方式, 随行人数, 备注；名额上限 | 免登录；手机号字段去重 | 二维码 + 实时报名名单 + 名额进度条 |
| 投票 | 选项单选/多选；投票人标识 | 免登录弱去重，或验证码登录一人一票 | 选项卡片 + 实时票数条 |
| 接龙 | 顺序号, 姓名, 接龙内容 | 免登录；追加式提交 | 接龙列表 + 一键复制文字版转发 |
| 信息登记（学员/员工） | 身份字段, 多项资料, 照片上传 | 手机验证码登录，一人一份可修改 | 表单 + 已提交确认页 |
| 家长收集（回执/材料） | 学生姓名, 班级, 材料 photo | 验证码登录或班级码 | 按班级分组汇总 + 未交名单 |
| 客户需求单 | 客户信息, 需求描述, 预算, 附件 | 免登录 + 提交成功页 | 需求列表（发起人后台）+ 转发话术 |

## 二、防重复填写策略（按场景选，不要全上）

1. **手机号去重**（免登录场景主力）：手机号字段加唯一约束，提交前查重，重复时提示「该手机号已填过」并可查看/修改自己的提交
2. **登录身份去重**（实名/一人一票场景）：手机验证码登录后按用户 ID 唯一约束，最可靠
3. **设备/链接参数去重**：弱约束，只防手抖双击，**不能**作为唯一防线
4. **截止时间**：到点自动关闭表单（前端隐藏入口 + 数据库层拒绝写入双保险），避免截止后还有人填

## 三、二维码与交付话术

交付物 = 填写页 URL + 二维码图片 + 汇总页链接 + 一段可复制的转发话术。四样缺一不可。

转发话术模板（用户可直接粘贴转发）：

> 【xx 活动报名】点链接或扫码填写：{url}　x月x日 截止，填过就不用再接龙了，有问题直接回复本消息。

注意事项：

- 汇总页是**另一个**链接（发起人登录后看），别把后台链接当成填写链接发出去
- 二维码直接生成图片文件交付，别只给一条短链接让用户自己去找生成器

## 四、汇总页设计要点

1. **顶部三卡**：已提交人数 / 名额进度（报名类）/ 今日新增
2. **明细表**：支持搜索、按字段筛选；一键导出 CSV（Excel 直接可开，注意 BOM 头避免中文乱码）
3. **未填名单**：报名类场景，对比「应填名单」（可选上传）与已提交名单，标出谁还没填
4. **截止倒计时**：距离截止的剩余时间
5. **实时性**：填写端提交后，汇总页刷新即可见——手动刷新足够，不要为这个做长连接
6. **开放题归纳**（可选，`ai-model-web`）：建议/备注类的自由文本自动归类成几个主题摘要
