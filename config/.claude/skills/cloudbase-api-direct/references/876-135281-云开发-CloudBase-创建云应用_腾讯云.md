## 1\. 接口描述

接口请求域名： tcb.tencentcloudapi.com 。

创建云应用

默认接口请求频率限制：20次/秒。

推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=tcb&Version=2018-06-08&Action=CreateCloudApp)

API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2\. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/876/34812) 。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：CreateCloudApp。 |
| Version | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：2018-06-08。 |
| Region | 否 | String | [公共参数](/document/api/876/34812) ，本接口不需要传递此参数。 |
| EnvId | 是 | String | 
环境ID

  
示例值：lowcode- ******\*\*\*\******* |
| ServiceName | 是 | String | 

服务名

  
示例值：my-vue-app-01 |
| DeployType | 是 | String | 

部署类型

  
示例值：custom |
| BuildType | 否 | String | 

构建类型

  
示例值：ZIP |
| StaticConfig | 否 | [StaticConfig](/document/api/876/34822#StaticConfig) | 

静态应用创建配置信息

 |
| Source | 否 | [BuildSource](/document/api/876/34822#BuildSource) | 

源码定义

 |
| Commands | 否 | [BuildCommands](/document/api/876/34822#BuildCommands) | 

Commands 与 CustomSteps 至少填一个

 |
| Env.N | 否 | Array of [Variable](/document/api/876/34822#Variable) | 

Commands 与 CustomSteps 至少填一个，docker 镜像构建场景强烈建议用 CustomSteps

 |
| CustomSteps.N | 否 | Array of [BuildStep](/document/api/876/34822#BuildStep) | 

非敏感环境变量，构建容器中以 $KEY 引用

 |
| Secrets.N | 否 | Array of [BuildSecret](/document/api/876/34822#BuildSecret) | 

敏感凭证（AES 加密落库），构建容器中以 $SECRET\_NAME 引用

 |
| NodeJsVersion | 否 | String | 

选择 NodeRuntime 版本: 16,18,20,22,24 等

  
示例值：22 |

## 3\. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| BuildId | String | 
构建Id

  
示例值： ****\*\***** |
| VersionName | String | 

版本名称

  
示例值：my-vue-app-01-001 |
| ServiceName | String | 

服务名称

  
示例值：my- **_\-_** -\*\* |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4\. 示例

### 示例1 创建 custom 服务

#### 输入示例

```
POST / HTTP/1.1
Host: tcb.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: CreateCloudApp
<公共请求参数>

{
    "EnvId": "lowcode-****************",
    "ServiceName": "my-vue-app-01",
    "DeployType": "custom",
    "Source": {
        "Type": "git",
        "Repo": "https://gi**u*********************-**********.git",
        "Ref": "master",
        "Channel": "github"
    },
    "CustomSteps": [
        {
            "Name": "ls",
            "Command": "node -v"
        }
    ],
    "NodeJsVersion": "22"
}
```

#### 输出示例

```json
{
    "Response": {
        "BuildId": "**********",
        "ServiceName": "my-***-***-**",
        "VersionName": "my-vue-app-01-001",
        "RequestId": "75628170-c5b9-4bda-b370-fec9dd4362f0"
    }
}
```

| 错误码 | 描述 |
| --- | --- |
| FailedOperation | 操作失败。 |
| InternalError | 内部错误。 |
| InvalidParameter | 参数格式或类型错误，如 Uin、EnvId、Domain 缺失或非法。 |
| LimitExceeded.ErrNamespaceMaxLimit | 命名空间超过配额。 |
| LimitExceeded.ErrRepoMaxLimit | 镜像容器超过配额。 |
| ResourceNotFound | 资源不存在。 |
