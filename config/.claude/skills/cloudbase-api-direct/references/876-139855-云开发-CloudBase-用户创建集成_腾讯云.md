## 1\. 接口描述

接口请求域名： tcb.tencentcloudapi.com 。

用户创建集成

默认接口请求频率限制：20次/秒。

推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=tcb&Version=2018-06-08&Action=CreateUserKey)

API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2\. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/876/34812) 。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：CreateUserKey。 |
| Version | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：2018-06-08。 |
| Region | 否 | String | [公共参数](/document/api/876/34812) ，本接口不需要传递此参数。 |
| EnvId | 是 | String | 
环境ID

  
示例值：asf2342-afds |
| Name | 否 | String | 

用户创建的集成名称，或者密钥名称

  
示例值：集成名称1 |
| KeyID | 否 | String | 

用户创建的集成ID，集成表示，或者密钥对标识，前半部分用户填写，后半部分平台按照一定规则生成

  
示例值：poiuas8-098asdfaf |
| Description | 否 | String | 

集成描述

  
示例值：这是个集成描述 |
| AuthTypeCode | 否 | String | 

集成类型，或者授权类型码，对应GetUserKeyTemplateList接口的AuthTypeCode字段，比如github、gitlab、gitee、meeting、PublicAccountOpenService等

  
示例值：github |
| Ext | 否 | String | 

根据集成类型的不同，ext会有不同的子结构，具体每种授权类型的ext需要填写的信息，可以通过GetUserKeyTemplateList获取

  
示例值：{"a":"b"} |
| TicketID | 否 | String | 

github、gitlab、gitee、腾讯会议等oauth类型的，需要传这个ticket\_id，创建的密钥对跟auth\_ticket\_token(对于github、gitlab、gitee)、weda\_ticket\_token(对于腾讯会议)关联起来

  
示例值：Zw3NdqeHfhInWHkNFq49 |
| Business | 否 | String | 

业务类型，integration：从集成中心来的，默认为空，表示是从授权管理中心来的

  
示例值：integration |
| RuntimeConfig | 否 | [AgentRuntimeConfig](/document/api/876/34822#AgentRuntimeConfig) | 

创建demo代码云函数需要的参数信息

入参限制：当Business为integration，且AuthTypeCode为(weixinmp、wxvirtualpay、weixin-store、channels、weixinpaydc)之一时必填

 |
| DemoCodeFunctionName | 否 | String | 

创建集成时创建关联的示例代码云函数的名称，当Business为integration，且AuthTypeCode为(weixinmp、wxvirtualpay、weixin-store、channels、weixinpaydc)之一时必填

  
示例值：wx-pay-04y48gfh-demo-scfweb |

## 3\. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| CreateResult | Integer | 
创建成功记录条数

  
示例值：1 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 6\. 错误码

以下仅列出了接口业务逻辑相关的错误码，其他错误码详见 [公共错误码](/document/api/876/34823#.E5.85.AC.E5.85.B1.E9.94.99.E8.AF.AF.E7.A0.81) 。

| 错误码 | 描述 |
| --- | --- |
| FailedOperation.ThirdServiceError | 请求第三方服务，第三方服务返回报错信息 |
| InternalError | 内部错误。 |
| InternalError.Database | 数据库错误。 |
| InternalError.Timeout | 服务超时。 |
| InvalidParameter | 参数格式或类型错误，如 Uin、EnvId、Domain 缺失或非法。 |
| InvalidParameter.EnvId | 环境ID非法。 |
| UnauthorizedOperation | 未授权操作。 |
| UnknownParameter | 未知参数错误。 |
