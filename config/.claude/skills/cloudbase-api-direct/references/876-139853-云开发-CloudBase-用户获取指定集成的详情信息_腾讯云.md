## 1\. 接口描述

接口请求域名： tcb.tencentcloudapi.com 。

用户获取集成详情

默认接口请求频率限制：20次/秒。

推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=tcb&Version=2018-06-08&Action=GetOneUserKey)

API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2\. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/876/34812) 。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：GetOneUserKey。 |
| Version | 是 | String | [公共参数](/document/api/876/34812) ，本接口取值：2018-06-08。 |
| Region | 否 | String | [公共参数](/document/api/876/34812) ，本接口不需要传递此参数。 |
| EnvId | 是 | String | 
环境ID

  
示例值：asf2342-afds |
| KeyID | 否 | String | 

用户密钥对标识，前半部分用户填写，后半部分平台按照一定规则生成

  
示例值：poiuas8\_098asdfaf |
| Business | 否 | String | 

业务场景来源，默认不传，表示来源授权中心，integration表示来源集成中心，当从集成中心请求时必传integration

  
示例值：integration |
| NeedPwd | 否 | Boolean | 

是否需要加密字段的值，true：是，false：否，默认不传，不需要

默认值：false

当为true时，返回加密字段的值，前端进行按约定解密

  
示例值：false |

## 3\. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| UserKeyInfo | [APIsUserKeyInfo](/document/api/876/34822#APIsUserKeyInfo) | 
单个密钥对详情页

 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4\. 示例

### 示例1 用户获取密钥对详情

#### 输入示例

```
POST / HTTP/1.1
Host: tcb.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: GetOneUserKey
<公共请求参数>

{
    "EnvId": "tcb-paas-e2e-main-vfc3g64mbqt7",
    "KeyID": "create_key_2"
}
```

| InvalidParameter | 参数格式或类型错误，如 Uin、EnvId、Domain 缺失或非法。 |
| InvalidParameter.EnvId | 环境ID非法。 |
| UnauthorizedOperation | 未授权操作。 |
