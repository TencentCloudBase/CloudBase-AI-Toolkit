# Codex Configuration Guide

Codex can install the CloudBase plugin through the **plugin marketplace** to get both MCP tool connectivity and AI Skills in one go, or connect manually via **MCP configuration**. The plugin marketplace approach is recommended.

**For example:**

- "Build a WeChat Mini Program ordering system with CloudBase" — AI scaffolds pages, creates the cloud database, writes cloud functions, and guides preview
- "Build a reservation management system that lets users place orders and admins update status" — AI models it with CloudBase PostgreSQL, configures permissions, and wires up frontend and backend
- "Add phone-number login to a Web app" — AI enables the auth method and integrates the CloudBase SDK

No need to switch to the cloud console — all operations can be done in Codex using natural language.

## Prerequisites

Before configuring, ensure the following conditions are met:

<details>
<summary><strong>Node.js environment and CloudBase environment ready</strong></summary>

**Node.js Environment:** Make sure Node.js v18.15.0 or later is installed:

```bash
node --version
```

If not installed, download from the [Node.js website](https://nodejs.org/en/download).

**CloudBase Environment:** See the guide [Create a CloudBase Environment](../../../quick-start/create-env). New users on the domestic site can try it for free.

</details>

<details>
<summary><strong>Git installed (required for the plugin marketplace)</strong></summary>

Codex runs `git clone` to fetch the marketplace repository, so a machine without `git` fails with `program not found`:

```bash
git --version
```

On Windows, install [Git for Windows](https://git-scm.com/download/win). After installing, **quit Codex completely and reopen it** so the new process picks up the updated PATH.

The MCP configuration approach (Method 2) does not require Git.

</details>

## FAQ

**Q: Adding the plugin marketplace fails with `failed to run git clone ... program not found`?**
A: Codex uses `git clone` to fetch the marketplace repository, and no usable `git` was found on this machine. Install Git for Windows, quit and reopen Codex, and make sure **Sparse path** is left empty.

**Q: MCP connection failed?**
A: Check if the command executed correctly, restart Codex, and verify your network connection.

**Q: Showing 0 tools?**
A: See the [FAQ](../faq#mcp-shows-0-tools).

**Q: Nothing changed after the plugin updated to a new version?**
A: Codex records each plugin install against a version, so refreshing the marketplace snapshot does not replace the copy that is already installed. Uninstall and reinstall once after updating:

```bash
codex plugin remove cloudbase@tencent-cloudbase
codex plugin marketplace upgrade tencent-cloudbase
codex plugin add cloudbase@tencent-cloudbase
```

In the Codex App, remove `cloudbase` from the plugin panel and install it again. Start a new thread afterwards so the plugin and its tools reload.
