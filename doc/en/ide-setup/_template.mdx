      "args": ["-y", "@cloudbase/npm-launcher@1.1.0", "@cloudbase/cloudbase-mcp@latest"],
      "env": {
        "INTEGRATION_IDE": "[IDE Name]"
      }
    }
  }

## FAQ

**Q: Connection keeps failing with `ENOTEMPTY`?**

A: Leftover files in the local npx cache. Fully quit [IDE Name], run the cleanup commands in the [FAQ](../faq#mcp-connection-fails-with-enotempty), then reconnect.

**Q: MCP connection failed?**

A: Check the config format, restart [IDE Name], and confirm your network is working.

**Q: Tool count shows 0?**

A: See the [FAQ](../faq#mcp-shows-0-tools).
