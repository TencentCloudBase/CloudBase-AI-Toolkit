# CloudBase AI 插件

一键把 CloudBase 接入 AI 编程助手：同时捆绑 [MCP Server](/ai/cloudbase-ai-toolkit/getting-started) 与 [Agent Skills](/ai/cloudbase-ai-toolkit/prompts/how-to-use)，安装后即可查库、管云函数、部署托管等，无需再分别配置。

相比单独装 Skills，插件还带上 Hooks 等能力，**Skill 激活更稳定**，推荐优先用插件。

**最快上手：** 复制下面的 AI Prompt，粘贴到你的 AI IDE。

```text
帮我把 CloudBase 接好，按下面做：
1. 打开 https://docs.cloudbase.net/skill.md，按说明完成接入。
2. 接入完成后告诉我，并建议最相关的下一步。
```

## 安装

### 方式 1：一键安装（推荐）

通过兼容 [Open Plugin Specification](https://open-plugins.com/plugin-builders/specification) 的 `plugins` CLI 安装，会自动检测本机 AI 工具。**优先用这条路径，不要手写 MCP JSON。**

默认 `--scope user`（全局）：

```bash
npx plugins add TencentCloudBase/cloudbase-plugin -y --scope user

# Sites 插件（可选）
npx plugins add TencentCloudBase/cloudbase-sites-plugin -y --scope user
```

### 支持的 AI IDE（`npx plugins targets`）

| `--target` ID | AI IDE | 说明 |
|---------------|--------|------|
| `claude-code` | Claude Code | `~/.claude` |
| `cursor` | Cursor | `~/.cursor` |
| `codex` | Codex | `~/.codex` |
| `grok` | Grok Build | `~/.grok`（仅 per-user） |
| `kimi` | Kimi Code | `~/.kimi-code`（仅 per-user） |
| `github-copilot` | GitHub Copilot CLI | `~/.copilot`（独立 `copilot` CLI，不是 `gh copilot`） |
| `vscode` | Visual Studio Code | Agent plugins（Preview，仅 per-user） |

不写 `--target` 时，会安装到本机**所有已检测到**的上述目标。查看检测结果：

```bash
npx plugins targets
```

只装某一个工具时：

```bash
npx plugins add TencentCloudBase/cloudbase-plugin -y --scope user --target cursor
```

安装后重启 / reload 对应工具即可。

> Agent 总入口（决策树 + 验收）：https://docs.cloudbase.net/skill.md

> Claude Code / Codex 的原生 marketplace 请用主仓库 `TencentCloudBase/CloudBase-MCP`；`cloudbase-plugin` 仓库由 CI 同步 OPS 标准内容，不含 marketplace 元数据。

> ⚠️ 已通过方式 2（`claude plugin install` / `codex plugin add` 等）安装过时，**不要**再对同一 IDE 执行 `npx plugins add`，以免重复实例。二选一即可。

### GitHub 不可达时（CNB 镜像）

`owner/repo` 短名会固定解析到 GitHub。若 `git clone` GitHub 失败，改用 **完整 CNB URL**（由 CI 从 OPS 产物同步，不含 marketplace 元数据）：

```bash
npx plugins add https://cnb.cool/tencent/cloud/cloudbase/cloudbase-plugin.git -y --scope user

# Sites 插件（可选）
npx plugins add https://cnb.cool/tencent/cloud/cloudbase/cloudbase-sites-plugin.git -y --scope user
```

> 不要用 monorepo 镜像 `CloudBase-AI-ToolKit` 做 `npx plugins add`：其 marketplace 结构与 OPS 专用仓不同，CLI 可能装不上。

若插件仍无法安装，可退回 Skills CNB 或 npm MCP，见 [skill.md](https://docs.cloudbase.net/skill.md)。

### 方式 2：按 IDE 手动安装

适用于 CodeBuddy（插件市场）、WorkBuddy、ZCode，或希望走 IDE 原生插件机制的场景：

<Tabs>
  <TabItem value="codex-app" label="Codex App">

1. 在 Codex App 右上角点 `+` → **添加插件市场**
2. 来源填 `TencentCloudBase/CloudBase-MCP`，Git 引用 `main`
3. 稀疏路径填两行（不要留空，否则会全量 clone，体积大且易失败）：
   - `.agents/plugins`
   - `plugin`
4. 在 **Tencent CloudBase** 市场中安装 `cloudbase`
5. 新开线程验证

  </TabItem>
  <TabItem value="codex-cli" label="Codex CLI">

```bash
codex plugin marketplace add TencentCloudBase/CloudBase-MCP --ref main \
  --sparse .agents/plugins \
  --sparse plugin
codex plugin add cloudbase@tencent-cloudbase
```

> Codex 认的是 `.agents/plugins/marketplace.json`（优先）或 `.claude-plugin/marketplace.json`。稀疏只拉 `plugin` 不够；全量 clone 约百兆级，弱网易失败。

新开线程后可用 `codex plugin list` 确认。

  </TabItem>
  <TabItem value="claude-code" label="Claude Code">

```bash
claude plugin marketplace add TencentCloudBase/CloudBase-MCP
claude plugin install cloudbase@tencent-cloudbase
```

安装后执行 `/reload-plugins`。默认 `--scope user`；团队共享可用 `--scope project`。

  </TabItem>
  <TabItem value="codebuddy" label="CodeBuddy">

1. 打开 CodeBuddy **插件市场** → **添加市场源**
2. 填入 `https://github.com/TencentCloudBase/CloudBase-AI-Toolkit`
3. 安装并启用 `cloudbase` 插件

CLI（CodeBuddy Code）等价命令：

```bash
codebuddy plugin marketplace add TencentCloudBase/CloudBase-AI-Toolkit
codebuddy plugin install cloudbase@tencent-cloudbase
```

**登录：**

- **有腾讯云账号**：直接对话，按提示完成 Device 登录
- **无腾讯云账号**：先 `npm i -g @cloudbase/cli`，再执行  
  `tcb login --cloudbase-api-key <cloudbaseApiKey> -e <cloudbaseEnvId>`

详见 [CodeBuddy 配置指南](ide-setup/codebuddy)。

  </TabItem>
  <TabItem value="workbuddy" label="WorkBuddy">

1. 对话输入框左下角点 **连接器**
2. 找到 **腾讯云 CloudBase** → **连接**

也可输入 `/cloudbase` 选择 Skill。详见 [WorkBuddy 配置指南](ide-setup/workbuddy)。

![WorkBuddy 内置 CloudBase 连接器](https://7463-tcb-advanced-a656fc-1257967285.tcb.qcloud.la/assets/workbuddy-connector-full.png)

  </TabItem>
  <TabItem value="zcode" label="ZCode">

ZCode（≥ 3.4.1）设置 → **插件** → **开发者工具** → 启用 **cloudbase-skills**。

也可在 **MCP 服务器** 中手动添加：命令 `npx`，参数 `-y @cloudbase/cloudbase-mcp@latest`。详见 [ZCode 配置指南](ide-setup/zcode)。

  </TabItem>
</Tabs>

### 其他 IDE

不走上述原生插件路径的工具（Cursor、WindSurf 等）可配置 MCP + Skills。选择你的工具查看步骤：

<IDESelector defaultIDE="cursor" showInstallButton={false} />

> CodeBuddy / WorkBuddy / ZCode 尚未实现 Open Plugin Specification，因此暂不支持 `npx plugins` 一键安装；请用各自原生路径（CodeBuddy 用插件市场，WorkBuddy 用连接器，ZCode 用内置插件）。

## 插件里有什么

| 能力 | 说明 |
|------|------|
| **MCP Server** | 环境、数据库、云函数、托管、存储、云托管、认证、权限、日志等，详见 [MCP 工具](mcp-tools.md) |
| **Agent Skills** | 平台、Web / 小程序、云函数、认证、数据库、AI 模型、UI 等专业知识，详见 [如何使用 Skill](prompts/how-to-use.mdx) |
