# OpenAI Codex CLI 配置指南

配置后，你可以在 OpenAI Codex CLI 的对话中直接操作 CloudBase 服务。

**例如：**

- “用云开发做一个微信小程序点餐系统” - AI 搭页面、建云数据库、写云函数并引导预览
- “做一个预约管理系统，支持用户下单和后台改状态” - AI 用 CloudBase PostgreSQL 建模、配权限并接好前后端
- “给 Web 应用加上手机号登录” - AI 启用认证方式并接入 CloudBase SDK

无需切换到云控制台，所有操作都可以在命令行中用自然语言完成。

## 前置条件

在开始配置之前，请确保满足以下条件：

<details>
<summary><strong>已准备好Node.js 环境和云开发环境</strong></summary>

**Node.js 环境：** 确保已安装 Node.js v18.15.0 或更高版本：

```bash
node --version
```

如果未安装，请从 [Node.js 官网](https://nodejs.org/en/download) 下载安装。

**云开发环境：** 请参考文档 [开通云开发环境](../../../quick-start/create-env)。国内站新用户可以免费开通体验。

</details>

<details>
<summary><strong>已安装 Git（插件市场方式需要）</strong></summary>

Codex 添加插件市场时会执行 `git clone` 拉取市场仓库，机器上找不到 `git` 会直接报 `program not found`：

```bash
git --version
```

Windows 用户请安装 [Git for Windows](https://git-scm.com/download/win)。安装后请**完全退出并重新打开 Codex**，新进程才会读到更新后的 PATH。

只用 MCP 配置方式（方式二）不需要 Git。

</details>

## 常见问题

**Q: 连接反复失败，提示 `ENOTEMPTY`？**
A: 本地 npx 缓存有残留文件。完全退出当前 AI 工具后，按[常见问题](../faq#mcp-连接报-enotempty-怎么办)里的命令清理一次，再重新连接。

**Q: 添加插件市场时报 `failed to run git clone ... program not found`？**
A: Codex 用 `git clone` 拉取市场仓库，这台机器上没有可用的 `git`。安装 Git for Windows 后完全退出并重新打开 Codex。

**Q: MCP 连接失败？**
A: 检查命令是否正确执行，重启 OpenAI Codex CLI，确认网络连接正常。

**Q: 工具数量显示为 0？**
A: 请参考[常见问题](../faq#mcp-显示工具数量为-0-怎么办)。

更多问题请查看：[完整 FAQ](../faq)
