# WorkBuddy 配置指南

配置后，你可以在 WorkBuddy 的 AI 对话中直接操作 CloudBase 服务。

**例如：**

- “用云开发做一个微信小程序点餐系统” - AI 搭页面、建云数据库、写云函数并引导预览
- “做一个预约管理系统，支持用户下单和后台改状态” - AI 用 CloudBase PostgreSQL 建模、配权限并接好前后端
- “给 Web 应用加上手机号登录” - AI 启用认证方式并接入 CloudBase SDK

无需切换到云控制台，所有操作都可以在 WorkBuddy 中用自然语言完成。

## 前置条件

在开始配置之前，请确保满足以下条件：

<details>
<summary><strong>已准备好Node.js 环境和云开发环境</strong></summary>

**Node.js 环境：** 确保已安装 Node.js v18.15.0 或更高版本：

```bash
node --version
```

如果未安装，请从 [Node.js 官网](https://nodejs.org/en/download) 下载安装。

**云开发环境：** 请参考文档 [开通云开发环境](../../../quick-start/create-env)。新用户可以免费开通体验。

</details>

## 使用内置连接器（推荐）

WorkBuddy 已内置 CloudBase MCP 连接器，不需要另外安装。两个入口进的是同一份列表：

- **对话里**：点输入框左下角的 **连接器**，在搜索框输入 `cloudbase`，选中 **腾讯云 CloudBase**，打开右侧开关
- **管理页**：左侧边栏 **专家** → **连接器** 页签，找到 **腾讯云 CloudBase**，点卡片上的 **+**，在弹窗中点 **连接**

连接器已在 WorkBuddy 开放平台公开发布，任何账号搜到的都是同一份；版本由 CloudBase 在这边维护，更新只替换连接器包本身，不需要重装 WorkBuddy。

搜索要用名字（`cloudbase` 或 `腾讯云开发`），不要描述需求，否则会返回一堆不相关的连接器。已经连上的连接器不会出现在搜索结果里，搜不到时先去已连接列表看一眼。

第一次启用会走一次授权。当前授权页只提供微信扫码，扫码同意后回到 WorkBuddy，连接器变成已连接状态即可使用。

> ⚠️ 只有环境级 API Key、没有可登录的腾讯云账号时，这一页过不去，因为连接器需要一个能扫码授权的账号。这种情况改用 CLI：`tcb login --flow web`（本机拉起浏览器，授权页上可选 “使用 API Key 登录”），或 `tcb login --cloudbase-api-key <key> -e <envId>`，然后在对话里让 Agent 直接调 CLI。

![WorkBuddy 内置 CloudBase 连接器](https://7463-tcb-advanced-a656fc-1257967285.tcb.qcloud.la/assets/workbuddy-connector-full.png)

![CloudBase 连接器详情](https://7463-tcb-advanced-a656fc-1257967285.tcb.qcloud.la/assets/workbuddy-connector-detail.png)

启用后，即可在对话中直接使用 CloudBase 的各项能力。
