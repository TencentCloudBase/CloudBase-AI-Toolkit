# Submit CloudBase to Qoder / QoderWork

## Package

Source of truth: `plugin/cloudbase/`

Required for Qoder:

- `.qoder-plugin/plugin.json` — generated by `node scripts/build-open-plugin-spec.mjs`
- `.mcp.json` — ships `npx @cloudbase/cloudbase-mcp@latest`
- `skills/` — CloudBase agent skills
- Optional: `.claude-plugin/` (also accepted by QoderWork Expert Kits)

Build + pack:

```bash
npm run pack:qoder-plugin
# → dist/cloudbase-qoder-v<version>.zip

npm run pack:qoder-skill
# → dist/cloudbase-skill-v<version>.zip  (entry skill: cloudbase/)
```

Local import (no zip):

```text
Qoder IDE → Plugin market → Import local folder → plugin/cloudbase
```
